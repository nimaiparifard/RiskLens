# API

Interactive docs: **http://localhost:8000/api/docs/** (Swagger, generated by drf-spectacular).
Raw schema: `/api/schema/` — `make types` turns it into TypeScript types for the frontend.

All endpoints except login/health require `Authorization: Bearer <access JWT>`.
Errors share one envelope: `{"error": "<code>", "detail": "<message>", ...extra}`.

## Public API (Django, port 8000)

| Method | Path | Role | Notes |
|---|---|---|---|
| POST | `/api/auth/token/` | – | `{username, password}` → `{access, refresh, user}`; access 15 min, refresh rotated + blacklisted |
| POST | `/api/auth/token/refresh/` | – | `{refresh}` |
| GET | `/api/auth/me/` | any | current user + role |
| GET | `/api/applications/?status=pending&grade=C&search=` | any | paginated, `status` repeatable |
| POST | `/api/applications/` | officer | `{applicant:{full_name,email}, features:{AMT_INCOME_TOTAL, AMT_CREDIT, DAYS_BIRTH, …}, history:{…}}` |
| GET | `/api/applications/{id}/` | any | incl. `latest_prediction` with `shap_reasons` |
| POST | `/api/applications/{id}/score/` | officer | calls serving, stores a `Prediction`, audit entry; throttled (`scoring`) |
| POST | `/api/applications/{id}/decision/` | officer / admin | `{decision: approve\|reject, comment}`; against the model ⇒ comment required; changing a final decision ⇒ admin |
| GET | `/api/applications/{id}/audit/` | any | immutable audit trail |
| GET | `/api/applications/stats/` | any | counts, approval & override rate |
| GET | `/api/predictions/?application=` | any | prediction history |
| POST | `/api/transactions/score/` | officer | real-time fraud check (raw IEEE-CIS fields) → `approved / review / blocked` |
| GET | `/api/transactions/?flagged=true&since_id=` | any | live feed (polled every 2 s by the UI) |
| POST | `/api/transactions/{id}/review/` | officer | `{label: fraud\|legit}` (ground truth) |
| GET | `/api/models/` | any | MLflow registry versions + metrics (champion vs challenger) + what serving runs |
| POST | `/api/models/reload/` | admin | hot-reload serving |
| GET | `/api/monitoring/drift/?task=credit` | any | drift reports (PSI per feature) |
| POST | `/api/monitoring/drift/run/` | admin | `{task, hours}` run now |
| GET | `/api/audit/?target_id=` | officer | global audit log |

### Example
```bash
TOKEN=$(curl -s localhost:8000/api/auth/token/ -H 'Content-Type: application/json' \
  -d '{"username":"officer","password":"risklens-demo"}' | jq -r .access)
curl -s -X POST localhost:8000/api/applications/$ID/score/ -H "Authorization: Bearer $TOKEN" | jq
```
```json
{
  "probability": 0.214, "score_points": 541, "grade": "D", "decision": "reject", "threshold": 0.167,
  "model_name": "risklens-credit", "model_version": "2", "latency_ms": 86.4,
  "shap_reasons": [
    {"feature": "EXT_SOURCE_3", "value": 0.18, "contribution": 0.61, "direction": "increases_risk",
     "text": "Low external credit bureau score (bureau 3)"}
  ]
}
```

## Internal serving API (FastAPI, port 8001)

| Method | Path | Notes |
|---|---|---|
| POST | `/v1/credit/score` | `{features:{…}, explain:true}` → `{probability, score_points, grade, decision, threshold, reasons[], model_version, latency_ms, shadow}` |
| POST | `/v1/credit/score/batch` | up to 5 000 items (Celery batch scoring) |
| POST | `/v1/fraud/score` | `{transaction:{…}, explain, record_history}`; < 50 ms p95 |
| GET | `/v1/model/info` | versions, thresholds, metrics, challenger |
| POST | `/v1/model/reload?task=` | header `X-Internal-Token` |
| GET | `/v1/model/reference?task=&n=` | training reference sample (drift) |
| POST | `/v1/monitoring/drift` | `{task, records[], scores[]}` → PSI per feature |
| GET | `/health`, `/health/ready`, `/metrics` | liveness, readiness (503 until a model is loaded), Prometheus |
